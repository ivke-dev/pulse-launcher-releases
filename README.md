# Pulse Launcher

Downloads for **Pulse Launcher**, a game launcher for Windows that brings Steam, Epic Games, GOG, EA app, Ubisoft Connect and Battle.net games into one library and measures your real playtime.

**[Download the latest version](https://github.com/ivke-dev/pulse-launcher-releases/releases/latest)**: get `PulseLauncherSetup.exe` and run it.

Pulse checks this page for new versions and offers to update itself.

Requires Windows 10 or 11 (64-bit).
